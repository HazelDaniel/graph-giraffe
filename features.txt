# OPEN FEATURES
 1.[] minimap/radar view (desktop only)

 2. simulation

 3[]. edge labels — GPU-rendered labels are implemented; interactive/custom label controls belong to the adapter overlay layer

 4[]. Command-based history system — replaces closures with serializable command objects + snapshots. This is foundational: it unblocks simulation (you
		can replay command streams), persistence (serialize state), and multiplayer (sync commands). There's already a skill for this.

 5[). Node type plugin/registry system — open up NodeType to a registry where each type declares its own: layout rules, handle config, rendering
		delegate, prop schema, reparenting constraints, default textures. This is the single most important architectural change for adding
		sliders/dropdowns/etc without touching 6 files each time.

 6. Animation/tweening engine — a lightweight tween system (not a full physics engine) that can drive: edge label position along edge paths, node
		position transitions, edge pulse/glow effects, camera smooth pan. This feeds into both the "handle-to-handle animation" feature and simulation.

 7[]. subgraphs — a re-usable family of primitives that can be collapsed/viewed as ordinary primitives
 8[]. hubs — primitives that support many to many connections on their two ports
 9[]. branches — primitives that allow for conditional branching. they look like rounded tiangles with two handles on both sides, and one on the top, supporting only outbound connections on both side and inbound connections on the top 
 10. type propagation — input and output types are inferred on connection to determine compatible types, validations rules are then inferred by the editor before runtime
 11[]. event handling — 
 12[]. import and export deliverables — this keeps the state of all primitives currently drawn on screen and exports it to a format that only the platform understands - perhaps a json (to avoid writing our own parser). the exported deliverable could then be imported and loaded to restore the states of all primitives and draw them on the screen
 13. sandboxing + (ts-wasm or ts-web-worker) rpc

- EVENT ACTIONS (undoable/redoable):
	* connection
	* deletion (node, edge, groupnode, composition)
	* creation (node, edge, groupnode, composition)
	* world-space translation (whether individual drags or in a multi-selection)
	* node prop change
	* label update
	* re-parenting
	* exporting selections to sub-graphs and un-graphing subgraphs
	* group node locking/unlocking
    * [others not yet mapped out]

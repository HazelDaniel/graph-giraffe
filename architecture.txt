[TEXTURE UPLOAD]
 The right model is:

  TextureSource -> CanvasImageSource -> WebGLTexture

  Where TextureSource is durable/editor state:

  interface TextureSource {
    id: string;
    label: string;
    kind: "node-body" | "node-head" | "group-body" | "group-head" | "composition-body" | "composition-head";
    sourceType: "default" | "upload";
    svgText: string;
    previewUrl?: string;
  }

  Then <gg-texture-select> should only be a UI picker. It should not create WebGL textures directly. It should emit a selected textureId, and a texture
  registry/service should handle SVG parsing, rasterization to canvas, caching, and WebGL upload.

  Important constraints:

  - SVG upload can work, but uploaded SVGs must be sanitized. Raw SVG can contain scripts, external references, embedded styles, remote images, and
    event handlers.

  - Conversion is async. SVG text becomes a Blob/data URL, then an ImageBitmap or HTMLImageElement, then canvas, then WebGL texture. The UI needs
    loading/error states.

  - Defaults should be registry entries too, not hardcoded theme branches. That way built-in and uploaded textures follow the same path.
  - Separate selectors are fine, but they should share one component and differ only by a filter like kind="node-head" or kind="group-body".
  - Texture IDs should live on node data, not WebGLTexture objects. WebGL textures are runtime resources; node state should store stable IDs like
    bodyTextureId, headTextureId.

  - Head/body split should happen before a full texture picker rollout. Current createTextTexture draws the whole node into one canvas texture, so
    selecting separate head/body textures will be awkward until the node visual model has explicit headTextureId and bodyTextureId.

  For <gg-texture-select>, the component API could look like:

  <gg-texture-select
    id="node-body-texture"
    name="nodeBodyTexture"
    kind="node-body"
    value="glass-dark">
  </gg-texture-select>

  And it emits something like:

  "gg-texture-select-change" -> {
    value: string;
    label: string;
    name: string;
    kind: TextureKind;
  }

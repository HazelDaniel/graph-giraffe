Graph Giraffe Overlay Primitives

Figma-style comment bubbles attached to the canvas. Toggle Comment mode (toolbar or the action pane), then click an empty area — a pin drops and a composer auto-focuses. Blur to save (an event fires; the demo holds its own chat state), or blur empty to cancel. Drag by the bubble header to move it. Load restores bubbles from stored state; Pan imperatively lerps the camera to a comment.
